# JavaUtilsGUI
A collection of utility classes providing tools and solutions for common problems in creating Graphic User Interfaces.<p><br>

Utility classes:
1. ImageUtil - reading and copping images. Size and orientation adjustments - scaling, cropping, rotating. Simple color adjustments like turning to grayscale and color inversion.
2. ColorUtil - colour adjusting tools, like adding transparency, finding gray scale equivalent or opposite of the colour provided.
3. GraphicsUtil - drawing, size adjusting and cropping String objects using the Graphics class.
4. GBC - a GridBagConstraints subclass designed for easier creation and management of a GridBagLayout.<p><br>

Adapters:
1. DragMouseAdapter - allows easy changes in the component's location by dragging it across the screen.
2. HighlightingMouseAdapter - highlights the component when the cursor enters its bounds, providing a few different highlight options.<p><br>

Components:
1. Buttons - a collection of custom buttons of different shapes and designs. Buttons extending the HighlightedButton class include a built-in highlight feature.
2. Panels - custom panel designs.
3. Statistical graphics - a progress bar and a progress chart for visual display of data.
